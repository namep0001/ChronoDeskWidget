# ChronoDesk Widget

A lightweight Windows 10/11 desktop widget with Gregorian and Solar Hijri calendars, tasks, quick notes, Pomodoro timer, bilingual English/Persian UI, TGJU market quotes, system-tray controls, and Windows theme integration.

## Download the complete project

Download `ChronoDeskWidget_Windows_Project.zip` from this repository's file list. The ZIP contains the complete project, source code, build scripts, README, and test report.

## Build

Extract the ZIP, then run `Start-Widget.bat` on Windows 10 or Windows 11. The launcher builds the app if needed. The executable is generated at `bin\\Release\\ChronoDeskWidget.exe`.

## Notes

The application is built with Windows Forms and .NET Framework 4.8. Market rates are fetched from TGJU; fresh rates require an internet connection. Windows compilation and runtime measurements should be performed on Windows.
