# Changelog

All notable changes to ChronoDesk Widget are documented here.

## [1.1.0] — 2026-11-01

### Added
- Network Monitor with live download and upload speeds, internet connectivity status, monthly totals, and daily usage.
- System Monitor with CPU, memory, GPU, system-drive, battery, and uptime metrics.
- Calculator widget with basic arithmetic, decimal input, and sign toggle.
- Three-column widget layout when more than two widgets are visible.
- Solar Hijri calendar weekday labels in Persian, using the B Roya font in both interface languages.

### Improved
- Network usage history is sampled while the application is running and stored locally by calendar month.
- Network Monitor cards use a consistent rounded layout and adapt to the available widget width.
- Project metadata, documentation, release automation, and project website are aligned with version 1.1.

## [1.0.0] — 2026-10-31

First official release of ChronoDesk Widget.

### Features
- Desktop clock with Gregorian and Solar Hijri date display.
- Gregorian and Solar Hijri calendar modes.
- Local task list with completion tracking.
- Pomodoro focus and break timer with circular progress.
- Quick notes with local persistence and UTF-8 text export.
- USD, EUR, and 18-karat gold market rates from TGJU.
- Toman and Dollar price display with daily percentage movement indicators.
- System, Light, and Dark themes with Windows accent color support.
- Adjustable widget opacity and font selection.
- Independent widget visibility controls and always-on-top behavior.
- Optional launch at Windows sign-in.
- English and Persian interface languages.
- System-tray controls and local settings persistence.

### Requirements
- Windows 10 or Windows 11.
- .NET Framework 4.8.
- No third-party runtime packages.
