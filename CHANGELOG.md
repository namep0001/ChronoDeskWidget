# Changelog

All notable project changes are documented here.

## [Unreleased]

### Added
- Three-column widget layout when more than two widgets are visible.
- Network monitor with live transfer speed and daily download/upload totals retained for the current calendar month.
- Calculator widget with basic arithmetic, decimal input, and sign toggle.
- System monitor with CPU, RAM, GPU, system-drive usage, laptop battery status, and uptime progress indicators.
- Local monthly network history stored in `network-month.csv` under the application data folder.

## [1.0] — 2026-10-31

First official release of ChronoDesk Widget.

### Features
- Desktop clock with Gregorian and Solar Hijri date display.
- Calendar with Gregorian and Solar Hijri modes.
- Local task list with completion tracking.
- Pomodoro focus and break timer with circular progress.
- Quick notes with local persistence and UTF-8 text export.
- Live USD, EUR, and 18-karat gold market rates from TGJU.
- Toman and Dollar price display with daily percentage movement indicators.
- System, Light, and Dark themes with Windows accent color support.
- Adjustable widget opacity and font selection.
- Independent widget visibility controls and always-on-top behavior.
- Optional launch at Windows sign-in.
- English and Persian interface languages.
- System-tray controls and local settings persistence.

### Release details
- Windows 10 and Windows 11.
- .NET Framework 4.8.
- No third-party runtime dependencies.
